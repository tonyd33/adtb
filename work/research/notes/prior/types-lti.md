---
title: Pierce and Turner, Local Type Inference (TOPLAS 2000)
---
Partial inference for subtyping plus polymorphism using only adjacent syntax-tree nodes: type arguments synthesized from local subtyping constraints, expected types propagated into lambdas and local bindings. Top-level functions are annotated by design. A Bot type makes joins and meets total. https://www.cis.upenn.edu/~bcpierce/papers/lti-toplas.pdf
