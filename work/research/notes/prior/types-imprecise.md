title: Peyton Jones et al., A semantics for imprecise exceptions (PLDI 1999)

In a pure language an erroring expression denotes a set of possible exceptions; operators union their operands' sets, so reordering stays valid; which member is reported is a nondeterministic choice made only when the computation runs. https://www.microsoft.com/en-us/research/wp-content/uploads/1999/05/except.pdf
