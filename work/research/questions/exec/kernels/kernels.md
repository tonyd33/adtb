Fixed constructor schemas mean each kernel is monomorphised per field
type and chosen once per pipeline; generics do the specialisation at
build time.

## exec/kernels/arrow-rs

`arrow::compute::filter`, `take`, comparison kernels. Operators
(scan of a constructor heap, union index probe, hash join) are the
engine's.

## exec/kernels/own

X100 generated hundreds of primitives from patterns.

```
macro_rules! cmp_kernel { ($name:ident, $t:ty, $op:tt) => {
  fn $name(a: &[$t], b: $t, sel: &[u32], out: &mut Vec<u32>) {
    for &i in sel { if a[i as usize] $op b { out.push(i) } } } } }
cmp_kernel!(lt_u64, u64, <);
```

## exec/kernels/datafusion

Each constructor heap is a `TableProvider`; a lowered match is a
`UnionExec` of arm plans. The engine's optimizer emits physical plans
directly, as Velox consumers do.
