`reindex secrets (salry)` answers differently from `reindex secrets (salary)` for a role holding `maintain` and no grant on `secrets`.

## security/reindex-fields/maintainer

An operator names what to rebuild, and rebuilding an index must be able to say the index is absent. The capability is the trust, as it is for relation names. It reveals index shape, never rows.

## security/reindex-fields/denied

An operator could not tell a mistyped index from a forbidden one, and every operator running this command would need to read the schema elsewhere first.
