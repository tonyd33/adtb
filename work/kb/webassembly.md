# WebAssembly specification

kind: language
home: https://webassembly.github.io/spec/

## Spec structure

- One repository holds the specification, a reference implementation and the official test suite. [V 2026-10-25] https://github.com/WebAssembly/spec
- Reference interpreter in OCaml written for clarity, not speed, "a device for nailing down exact semantics"; runs scripts of modules, invocations and assertions, the test format. [V 2026-10-25] https://github.com/WebAssembly/spec/blob/main/interpreter/README.md
- Spec built with SpecTec (CI badge in repo). [S 2026-10-25] same repo README
