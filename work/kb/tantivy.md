# Tantivy

kind: system
home: https://github.com/quickwit-oss/tantivy

- Rust full-text search library after Lucene: BM25, phrase queries, configurable tokenizers and stemmers, incremental indexing with a commit model, segments, fast fields, facets, mmap directory, multithreaded indexing; no distributed search.
