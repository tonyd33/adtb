# InvenTree

kind: system
home: https://inventree.org/

## product

- Open-source (MIT) inventory system with a Python/Django backend, web admin interface and REST API; self-hosted; stock control and part tracking; aimed at SMEs and hobbyists. [S 2026-10-26] https://alternativeto.net/software/inventree/about
- Third-party CLI tools import parts from DigiKey, LCSC and Mouser into InvenTree. [S 2026-10-26] https://pypi.org/project/inventree-part-import
