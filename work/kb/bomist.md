# BOMIST

kind: system
home: https://bomist.com/

## pricing

- Free tier: 100 parts, 3 products. MAKER $15/month billed yearly (1 user, up to 1,000 parts, local workspaces, barcode labels, REST API). PRO $50/month billed yearly (no limits, sub-assemblies, production planning, procurement, lot control). TEAM $175/month (unlimited users, managed cloud database, sync). ENTERPRISE from $350/month, with on-premises and offline license options. [V 2026-10-26] https://bomist.com/pricing
- Desktop app; all plans support local workspaces. Subscription only, no perpetual license below Enterprise. [V 2026-10-26] https://bomist.com/pricing

## user feedback

- EEVblog users ask for a perpetual license, hierarchical storage locations (rack, drawer, slot), sub-assemblies and variants, and distributor barcode scanning (Digikey, Mouser, Farnell, Wurth); one reports 15-second delays creating a part; another praises that it "runs locally, so no server nor setup required". [V 2026-10-26] https://www.eevblog.com/forum/projects/bomist-parts-inventory-and-bom-management-for-electronics/
