# SQLCoq (Benzaken and Contejean)

kind: paper
home: https://hal.science/hal-01830255

## Semantics

- Coq mechanised, executable semantics for select [distinct] from where group by having with NULL, functions, aggregates, quantifiers and correlated subqueries; proven equivalent to a Coq bag relational algebra; extracted to OCaml as a certified semantic analyser. [V 2026-10-25] Benzaken, Contejean, "A Coq mechanised formal semantics for realistic SQL queries", CPP 2019, https://hal.science/hal-01830255/document
- Validated by comparing results with PostgreSQL and Oracle. [V 2026-10-25] same
- Part of the DataCert ANR project (ANR-15-CE39-0009). [V 2026-10-25] same
